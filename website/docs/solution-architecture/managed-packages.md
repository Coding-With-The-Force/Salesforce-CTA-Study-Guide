### Document Management System Managed Packages

**[XFiles Pro](https://www.xfilespro.com/)** - For exposing, creating and updating documents in external document storage systems within Salesforce (like sharepoint, custom hosted doc storage, etc). It can also be used for document generation.

**[DocuSign](https://www.docusign.com/solutions/salesforce)** - For document generation and e-signatures. This is hosted off platform and just has a salesforce connector. Users need both a docusign license in SF and in DocuSign.
